# Crypto Trading Journal

**This project is continued as [AutarkTrade](https://github.com/Mouses007/AutarkTrade).**
This repository is no longer developed.

## Existing installations

Make a backup of your database first.

- **Git install:** click *Update* in the app once (you get the bridge version 3.15.0), then once more — AutarkTrade is installed and your database (SQLite or PostgreSQL) is taken over on the first start.
- **Docker:** `mouses007/trading-journal:latest` now points to the AutarkTrade image, so a normal update (`docker compose pull && docker compose up -d`) brings AutarkTrade. For new installs use `ghcr.io/mouses007/autarktrade:latest` — see the [AutarkTrade Docker guide](https://github.com/Mouses007/AutarkTrade/blob/master/DOCKER.md).

## New installations

Please install [AutarkTrade](https://github.com/Mouses007/AutarkTrade) directly.
